# Security and privacy

This package does not collect telemetry, call remote model APIs, or transmit images, depth maps, geometry, or credentials. Runtime browser dependencies are vendored.

Point-cloud and mesh files are resolved beneath ComfyUI's active output directory. Browser-side screenshots and mesh downloads occur only after the user presses the corresponding control.

Do not include sensitive source media in public workflows or issue reports. Use GitHub private vulnerability reporting when available; otherwise contact the maintainer without attaching private data to a public issue.
