# Changelog

## 3.0.0

- Added normalization, colormap, surface-normal, range-mask, cleanup, and statistics nodes.
- Added binary PLY point-cloud export and a zero-dependency glTF 2.0 GLB depth-mesh writer.
- Added video-ready parallax frame and validity-mask generation.
- Upgraded the live viewer with adaptive mesh quality, wireframe, 16-bit depth previews, passthrough outputs, cached output restoration, iframe reconnects, offscreen rendering, and WebGL recovery.
- Completed the pinned Three.js r185 module set and added real ComfyUI workflow/API proof, cross-platform CI, and official Registry publishing.
